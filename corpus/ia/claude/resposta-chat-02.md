# Linguagem Python

## O que é

Python é uma **linguagem de programação de alto nível, interpretada e de propósito geral**. Foi criada por **Guido van Rossum** e lançada em 1991. O nome vem do grupo de comédia britânico *Monty Python*, e não da cobra.

## Principais características

- **Sintaxe simples e legível:** o código se parece com a linguagem humana, o que facilita o aprendizado.
- **Interpretada:** o código é executado linha a linha, sem necessidade de compilação prévia.
- **Tipagem dinâmica:** não é preciso declarar o tipo das variáveis.
- **Multiparadigma:** suporta programação orientada a objetos, procedural e funcional.
- **Multiplataforma:** roda em Windows, macOS e Linux.
- **Código aberto e gratuita**, com uma comunidade enorme.
- **Vasto ecossistema de bibliotecas**, que acelera o desenvolvimento.

## Exemplo de código

```python
nome = "Maria"
idade = 25

if idade >= 18:
    print(f"{nome} é maior de idade.")

    print(f"{nome} é menor de idade.")
```

## Vantagens

- Fácil de aprender, ótima para iniciantes
- Alta produtividade (menos linhas de código)
- Grande demanda no mercado de trabalho
- Comunidade ativa e muita documentação

## Desvantagens

- **Mais lenta** que linguagens compiladas, como C++ ou Rust
- **Alto consumo de memória** em alguns casos
- Não é a melhor opção para **desenvolvimento mobile** nativo
- Limitação no uso de múltiplos núcleos de CPU em threads (por causa do GIL)

## Resumo

Python é uma linguagem **versátil, fácil e poderosa**, usada desde a automação de tarefas simples até projetos complexos de inteligência artificial. Por isso, é uma das linguagens mais populares do mundo.
