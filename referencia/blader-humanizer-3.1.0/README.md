# Referência: Humanizer 3.1.0

Para reproduzir a linha de base:

```
python scripts/reescrever.py --skill referencia/blader-humanizer-3.1.0/humanizer-3.1.0.md --nome blader-3.1.0 --perfil <perfil> --modelo <modelId>
```
