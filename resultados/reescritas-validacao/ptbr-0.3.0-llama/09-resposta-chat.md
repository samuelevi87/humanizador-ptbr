A Lei Geral de Proteção de Dados (LGPD) vigora no Brasil desde 2020 e define regras para empresas sobre coleta, uso, armazenamento e proteção de dados de clientes.

Para lojas virtuais pequenas, as principais mudanças incluem informar claramente quais dados são coletados dos clientes, como nome, e-mail, CPF, endereço e telefone, e explicar para que esses dados serão usados, como entrega do pedido ou envio de promoções. Além disso, a loja deve permitir que o cliente peça a exclusão de seus dados pessoais quando aplicável e ter mais cuidado com o armazenamento e uso das informações dos clientes.

Se a loja descumprir a LGPD, pode sofrer multa de até 2% do faturamento, limitada a R$ 50 milhões por infração.
