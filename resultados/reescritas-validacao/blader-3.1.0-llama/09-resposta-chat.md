A LGPD (Lei Geral de Proteção de Dados) é a lei brasileira de proteção de dados pessoais, em vigor desde 2020. Ela define como empresas devem lidar com dados de clientes.

Para uma loja virtual pequena, as principais mudanças incluem informar claramente quais dados são coletados, como nome, e-mail e endereço, e explicar para que serão usados, como entrega de pedidos ou envio de promoções. A loja também deve permitir que os clientes solicitem a exclusão de seus dados pessoais quando aplicável e ter cuidado com o armazenamento dessas informações.

Se a loja descumprir a LGPD, pode sofrer multa de até 2% do faturamento, limitada a R$ 50 milhões por infração.
