A LGPD (Lei Geral de Proteção de Dados) é a lei brasileira de proteção de dados pessoais, em vigor desde 2020. Ela define regras sobre como as empresas devem coletar, usar, armazenar e proteger os dados de clientes.

Para uma loja virtual pequena, as principais mudanças são:

- Informar claramente quais dados são coletados dos clientes, como nome, e-mail, CPF, endereço e telefone.
- Explicar para que esses dados serão usados, por exemplo entrega do pedido, emissão de nota fiscal, atendimento ou envio de promoções.
- Permitir que o cliente peça a exclusão dos próprios dados pessoais, quando aplicável.
- Ter mais cuidado com o armazenamento e o uso das informações dos clientes.

Se a loja descumprir a LGPD, pode receber multa de até 2% do faturamento, limitada a R$ 50 milhões por infração.
