A LGPD (Lei Geral de Proteção de Dados) é a lei brasileira de proteção de dados pessoais, em vigor desde 2020. Ela define como as empresas devem coletar, usar, armazenar e proteger os dados dos clientes.

Para uma loja virtual pequena, isso muda quatro coisas:

- A loja precisa informar quais dados coleta dos clientes, como nome, e-mail, CPF, endereço e telefone.
- Precisa explicar para que usa esses dados, por exemplo: entrega do pedido, emissão de nota fiscal, atendimento ou envio de promoções.
- O cliente pode pedir a exclusão dos dados pessoais dele, quando aplicável.
- O armazenamento e o uso das informações dos clientes exigem mais cuidado.

Quem descumpre a LGPD pode levar multa de até 2% do faturamento, limitada a R$ 50 milhões por infração.
